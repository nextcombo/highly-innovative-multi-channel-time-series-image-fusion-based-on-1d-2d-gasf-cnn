# Highly innovative! Multi-channel time-series, image fusion based on 1D-2D-GASF-CNN-GRU-AT for multimodal data classification/fault recognition.

The application platform is MATLAB 2023 and above.
This algorithm combines the multimodal fusion of CNN-GRU-Attention for fault identification with 1D time series-2D Gram-Charlier Field (GASF) image data, based on the convolutional neural network (CNN)-gated recurrent unit network (GRU)-attention mechanism for data classification prediction/fault identification. It has a very high level of innovation and can be implemented immediately upon acquisition.
The fault classification model utilizes 1D time series and GASF image fusion inputs, combined with CNN-GRU-Attention for fault classification.
Program introduction: This algorithm employs dual input paths, requiring only raw fault waveform data. It converts a one-dimensional sequence into a two-dimensional Gram-Charlier Field (GASF) image based on the waveform data. One path involves extracting features from the GASF image through CNN, while another path directly inputs fault waveforms to GRU to extract temporal features. The temporal high-dimensional image features and one-dimensional time series features are fused. The multi-head attention mechanism effectively captures the contribution of extracted features, focusing on key features to enhance accuracy in fault identification. It also calculates evaluation metrics such as precision, recall, accuracy, F1 score, etc.
Content:
1. Two Excel files containing fault datasets - training set and test set
2. A program that modifies resolution and converts time series to images based on Gram-Charlier Field (GASF) difference field (GADF)
3. A program for fault diagnosis using CNN-GRU-Attention for multimodal fusion of time series and image attention mechanisms.
Innovation points:
1. Multimodal fusion: The integration of one-dimensional time series signals and two-dimensional images allows for the comprehensive use of different modalities, thereby more comprehensively describing the characteristics of the data. This helps to extract richer and more discriminative features, thus improving the accuracy of classification and identification.
2. Temporal Information Acquisition: GRU (Gated Recurrent Unit) is a type of recurrent neural network suitable for time-series data, capable of capturing dynamic changes and trends within one-dimensional temporal signals. By integrating GRU with CNN, the algorithm can simultaneously consider both temporal and spatial features, further enhancing its performance.
3. Spatial Feature Learning: Convolutional Neural Networks (CNN) have demonstrated excellent performance in image processing, effectively learning spatial features and local patterns of images. Applying CNN to the processing of image data can help extract features such as texture, shape, and edges from images, which is beneficial for more accurate classification and fault identification.
4. Integration Advantage: By integrating information from different modalities, the algorithm can compensate for the limitations of one-dimensional time-series signals and two-dimensional images. For example, images may be more sensitive to certain fault patterns while sequential signals are more sensitive to others. Combining them can enhance the robustness and generalization ability of the algorithm.
5. Multi-head Self-Attention Mechanism: This mechanism effectively captures the contribution of feature extraction, focusing on enhancing key features to improve the accuracy of fault identification.
6. Enhance Generalization Ability: Multimodal fusion can help algorithms better understand the essential characteristics of data, thereby reducing the risk of overfitting and enhancing the algorithm's generalization ability on new data.
Applicable fields: Suitable for various data classification scenarios, such as rolling bearing faults, transformer oil gas faults, power system transmission line fault areas, insulators, distribution networks, and disturbances to power quality.
